# researchnetwork

Work on research networks: co-authorship, citation and topic graphs.

## Layout

- Repo root: code, notebooks and data prep.
- `docs/`: the public website, served by GitHub Pages at
  **https://eeporter.github.io/researchnetwork/**

Only what's in `docs/` is published. Put a page in `docs/` (for example
`docs/coauthors/index.html`) and link it from `docs/index.html` to publish it.
